# Offscreen
A responsive screen-time competition prototype. No dependencies or build step.

## Run
`npm start` then open http://localhost:5173

## Check
`npm test`

## Planned work
See [TODO.md](TODO.md) for the proposed screen-time screenshot import.

## Try
Log today's screen time and watch your ranking change. Join a challenge, send kudos, and set your daily goal. Choices persist in localStorage.

## Prototype scope
Friends, dates, activity, and historical statistics are fictional demo data. Entries are manual, stored locally, and represent a fixed demo day (October 26). No device tracking, authentication, shared database, or real multiplayer is implemented. Real competition needs verified native device integrations and server-side ranking.
